# 请求响应速度

测速显示在 Claude Code 状态栏和「用量与日志 → 用量统计」，单位统一为 `tok/s`（Token/秒）。

## 查看位置

- 状态栏第二行显示 `Last 100.0 tok/s │ TTFT 2.00s`，表示当前受管理实例、当前线路最近一次已结束的普通请求。随 Claude Code 状态栏刷新更新。
- 用量统计顶部显示平均首 Token 延迟和加权输出速度；最近请求列表与详情显示每次请求的速度、首 Token 延迟和总耗时。
- 供应商／Key 弹窗保留用量、线路质量与延迟指标，速度集中到上述两个入口。

## 指标含义

| 指标                | 含义                                                      |
| ------------------- | --------------------------------------------------------- |
| TTFT／首 Token 延迟 | 请求进入代理，到首次收到文字、思考或工具调用内容的时间    |
| 总耗时              | 请求进入代理，到响应流结束的时间                          |
| 输出速度            | 上游输出 Token ÷ 首次至末次有效输出片段的时长，单位 tok/s |
| 平均输出速度        | 有效输出 Token 总数 ÷ 对应输出时长总和，按时长加权        |

例如，两次请求分别输出 1000 Token／10 秒、400 Token／2 秒，汇总为 `116.7 tok/s`。输入和缓存 Token、首 Token 前的等待、输出完成后的心跳与收尾等待不计入速度。

这是代理观测值，仍受网络分块、上游缓冲及上游输出用量（可能含思考 Token）影响。比较相同模型、相近任务时，可结合 TTFT、速度与成功率阅读。

## 缺失数据与升级

更新应用后重启本地服务，新请求开始采集末次输出时间，数据库自动迁移。旧记录不会补算速度，已有首 Token 延迟、耗时和用量保留。

无法测速时显示 `—`：包括旧记录、非流式、压缩后集中解析、整段一次送达、失败、取消及无有效输出时长。状态栏无测速样本显示 `Last — tok/s`，无首 Token 计时显示 `TTFT —`。非托管会话不显示其他实例的数据，Auto mode 分类请求不覆盖普通请求的状态栏读数。
