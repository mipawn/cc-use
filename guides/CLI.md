# 命令行工具使用指南

`cc-use` 只是终端客户端的启动入口，不承担实例管理、切换或统计。Codex Desktop 与
Claude Desktop 继续在桌面应用里打开和管理。

## 安装

应用 → 设置 →「命令行工具」→ 安装。它会把应用内二进制链接到
`/usr/local/bin/cc-use`。

## 使用

```bash
cd 你的项目目录
cc-use claude
cc-use grok
```

两个命令都会：

1. 显示该客户端可用的供应商与密钥列表；
2. 预选 GUI 中当前项目为该客户端配置的默认线路；
3. 用上下方向键高亮选择，回车使用当前项；
4. 按 `q` 取消；确认后在当前终端启动客户端，不弹出新终端窗口。

选择只影响本次启动，不修改 GUI 默认配置。当前目录未配置项目时，仍会列出全部兼容
线路，并预选第一项。daemon 未运行时会直接提示先打开 CC Use，不会启动一个无法请求的
客户端。

CLI 的公开命令只有 `claude` 和 `grok`。运行后的线路管理、用量查看与默认配置都在 GUI
中完成。

设置页同时提供更新、重新安装与卸载。卸载只移除 `/usr/local/bin/cc-use`，不会删除应用、
配置或用量数据。

## Claude Code 状态栏

状态栏是独立的可选能力：进入 Claude Code 页 →「状态栏」Tab，由用户主动启用。
它以彩色双行状态栏显示模型、Git 分支、上下文占用，以及当前 CC Use 实例、供应商
和 Key；不依赖全局安装 CLI。普通 Claude Code 会保留模型、Git 与上下文信息，并把
线路标记为 `unmanaged`。

已有第三方 `statusLine` 时，界面会让用户选择保留现有配置或备份并覆盖；点击恢复会还原
被替换的第三方配置。Claude Code 会在下一次交互时自动刷新，无需重启。

## 退出码

| 码  | 含义                                 |
| --- | ------------------------------------ |
| 0   | 成功                                 |
| 1   | 服务未运行、没有兼容线路或启动失败   |
| 2   | 当前不是可交互终端，无法完成列表选择 |
