# CC Use GUI 完整改版：配置、运行控制与观测

## 目标

围绕用户以 `cc-use` 命令启动客户端的实际用法，完整重组 GUI 信息架构、页面布局、选线与观测链路。保留首页年度热力图和当日统计，不再把 GUI 设计成项目启动器；一次集成交付，不分成若干体验不完整的产品版本。

## 非目标与禁止项

- 不删除项目、请求或用量历史，不改CLI的工作目录、显式选线、默认绑定、前置命令、心跳与退出语义；只修正过时的「GUI 默认」称谓。
- 不做项目管理替代品、GUI终端启动按钮、新持久化“线路”实体或自动换线。
- 不做外部客户端重启探测、自动重启、无依据的“已加载/已验证可用”。
- 不重做代理采集、额度计算、日志落盘架构，不新增独立日志页或将控制台变回请求表格。
- 不为已删除资源重建无法恢复的历史归属，不按显示名称猜测关联；不新增缺少历史快照的客户端账本筛选。
- 不换技术栈、升级依赖、自动提交或发布；不使用真实密钥、客户端配置、daemon重启做演示验收。

## 关键设计决定

1. 项目只是保留的CLI兼容数据，不再是GUI导航对象；托盘项目启动也移除，避免残留第二启动链路。
2. Claude/Grok运行实例合并，Desktop接入合并；统一界面不等于抹平客户端能力与配置实现差异。
3. 选线统一可读摘要、状态和恢复动作，资格校验通过client/gateway上下文区分。无线路时就地新增，成功返回并选中，但仍由用户确认应用。
4. 配置保存、额度刷新、桌面配置同步是不同结果；后两者失败不能把已保存状态说成失败或全部成功。
5. 统计是持久化账本；控制台是有限留存流。通过requestId衔接，不把缓冲过滤冒充完整历史。
6. 新增契约为只读统计过滤、窄控制台查询、结构化桌面操作/状态；保持共享Rust/TS/IPC原子一致，无数据库破坏迁移。

## 验收标准

- [x] **A1 概览**：今日Token/请求/失败、全年热力图及年份切换保留；无项目/启动卡占据主内容。热力图错误可重试，不显示为零使用。
- [x] **A2 精确钻取**：本地日期格与今日指标进入正确日期；请求按有Token口径筛选，失败按非success口径；从有用量切失败自动取消with_usage限制；返回保留日期。
- [x] **A3 导航清理**：无项目管理/启动/项目统计入口和托盘最近项目菜单；四旧客户端路由均正确重定向，设置与非项目托盘功能仍可达。
- [x] **A4 CLI兼容**：旧绑定预选、最深路径匹配、前置命令、无项目启动、非TTY行为/退出码、managed实例创建与session更新测试通过；数据库与历史总量不因删除UI改变。
- [x] **A5 实例列表**：完整活跃列表与各客户端最近结束记录分开获取；历史范围有说明，长期运行实例不被recent100限制漏掉；Claude别名、多实例同目录、stale状态正确。
- [x] **A6 实例操作**：按真实客户端限制选线，逐行pending、防双击；失败保留选择与原因，停止/删除并发时不误报成功；不改其他实例和未来默认。Claude会话及工具可达。
- [x] **A7 桌面事实**：读取中/官方/接管/未找到/错误独立；配置预览与恢复保留。结构化区分纯网关换线、配置写入、恢复，不解析成功字符串或宣称已重启。
- [x] **A8 说明持久性**：配置变更→纯换线→重开GUI后仍保留变更说明；恢复官方也有重开说明；托盘/密钥同步入口一致；重复无变化启动同步不刷新说明版本。新请求不被当作模型已加载证明。
- [x] **A9 部分失败**：文件失败/session已变更、回滚失败、状态回读失败、密钥保存成功但profile同步失败均有真实可恢复反馈；unknown不伪装官方/成功。
- [x] **A10 选线可判断**：模型摘要、状态原因、额度单位/归属/多窗口/更新时间可见；未知不是0、缓存不是健康保证。停用/耗尽/不兼容不可应用且说明原因。
- [x] **A11 配置闭环**：无资源→创建供应商/密钥→返回原实例/桌面/网关选择器并选中新项；仍需应用确认。取消/保存失败不丢原草稿；数据刷新不清空搜索或选择；新供应商不会被旧筛选隐藏。
- [x] **A12 保存与查询**：持久化完成即可退出保存，原有自动额度刷新异步继续；额度失败保留旧缓存并标失败/过时，支持重试，不报告为保存失败。账户和key查询控制遵守queryScope。
- [x] **A13 完整统计**：provider/key/instance稳定ID过滤在SQL聚合、计数和LIMIT之前生效；跨页混合fixture验证汇总、趋势和行范围一致；日期非法/删除资源/实例清理均显式反馈，不降级全量或按名称猜测。
- [x] **A14 控制台定位**：requestId精确查询覆盖留存内但全局500缓冲之外的事件；定位投影独立，清空generation阻止迟到事件复活。无记录、超窗、读取失败区分；返回恢复账本scope。
- [x] **A15 控制台兼容**：仍是终端式单行流，请求/异常/运行日志、搜索、暂停/继续、复制、详细模式、清空保持；无新独立日志页、资源过滤大面板或日志详情页面。
- [x] **A16 模型和网关**：供应商唯一模型清单管理入口、key选择映射与旧ID保留；网关换线/目录失败不重置或扩大modelPolicy与ID，只有显式修改保存才改变策略；连接配置不从key客户端配置继承。
- [x] **A17 历史能力**：网关启用/绑定/本地token显隐复制/LAN提示、资源用量和质量趋势、设置备份/导入导出/CLI安装/升级能力未被改版误删。
- [x] **A18 交互质量**：所有关键按钮pending与失败恢复一致；刷新不丢草稿/过滤/暂停；迟到响应不覆盖新身份；可访问名称、焦点返回、Enter/Escape语义与危险操作确认正确。
- [x] **A19 视觉验证**：浅/深色、中/英、1440×1000与900×700、长名称、空/错误/加载/耗尽/多实例均验证；仅密集区域局部滚动，reduce-motion生效，无整页溢出。
- [x] **A20 质量与安全**：相关单元/组件/IPC/Rust测试及typecheck、lint、前端构建通过；使用严格合成fixture经ego-browser验收；真实Keychain/配置/daemon零访问，URL/错误/截图不含凭证或session token；最终diff审查记录完成。

## 风险、兼容与延期边界

- 历史项目配置仍参与CLI启动：保留是为了兼容，不将旧数据删除冒充简化。今后若迁移CLI配置应另立任务。
- 已删除资源/已清理实例可能失去可查询归属；总账本仍在，但旧深链必须明确失效。不可变来源ID快照与历史修复不在本任务中。
- Desktop配置写入非单一数据库事务；通过临时目录/测试库覆盖部分成功，真实客户端重开由用户自行完成。
- 纯fixture浏览器验证不能替代Tauri原生集成证明。交付报告必须分别列已验证项与需人工确认项，不将前端截图宣称真实接管成功。
- 回退依靠代码回退；保留旧数据/共享API，新增settings记录可被旧版本忽略，不做删表/删数据迁移。
