# 统一供应商与密钥额度查询交互

## Goal

让普通用户通过选择内置查询方案、填写必要凭据、测试结果即可配置额度查询，不再默认面对 JavaScript；供应商账户级与密钥级保持一致的交互语言，同时明确各自查询的额度归属。进阶用户仍可主动进入自定义脚本。

## Background and Confirmed Facts

- 用户于 2026-11-09 同意创建规划任务，并明确要求同时改造供应商级和密钥级查询；本轮要求继续并完成该任务。产品决策已全部收敛为 D1–D5，待用户批准最终规划摘要后进入实施。
- 供应商编辑默认展开高级设置，查询模板只替换文本，随后直接展示代码、变量与 extractor 字段说明：`src/renderer/components/providers/ProviderModal.tsx:118-120,499-558`。
- 密钥新增/编辑默认进入额度查询标签页；即使关闭查询，仍展示被禁用的脚本编辑器：`src/renderer/components/keys/KeyEditModal.tsx:83-87,158,495-523`。
- Command Code 账户级查询组合 credits、subscriptions、summary 三个接口，并处理套餐映射及响应兼容，不应要求普通用户维护该逻辑：`src-tauri/src/shared_runtime/account_scripts.rs:144-285`。
- 当前存在用户未提交的 Command Code 脚本修复与数据库升级等改动；本任务不得覆盖或回退。
- 密钥草稿取供应商 `defaultKeyConfig.usageScript`，没有则用账户余额示例；新增默认关闭查询，但仍默认展示代码，关闭已有查询会清空已保存脚本：`src/renderer/utils/apiKeyEditor.ts:114-125,156-161`、`src/renderer/components/keys/KeyEditModal.tsx:133-154,277-300`、`src/renderer/components/keys/KeyEditModal.component.test.tsx:394-447`。
- 现有内置目录没有配置独立密钥查询默认值；Rust `DefaultKeyConfig` 尚无 TS 已声明的 `usageScript` 字段：`src-tauri/src/shared_runtime/provider_presets.rs:40-64,175-194,199-233,241-268`、`src/shared/types/index.ts:295-305`。
- 已有 New API 密钥查询适配为 `/api/usage/token/`，与账户接口区分；DeepSeek、OpenCode Go、Command Code 当前目录中的适配被定义为账户余额/套餐用量：`src-tauri/src/shared_runtime/account_scripts.rs:26-44,47-50,85-97,99-135,144-161`。这是当前支持能力，不等于供应商永远没有其他接口。
- 密钥执行器可使用当前密钥运行同构脚本，也保留供应商账户令牌与用户 ID；不能以“使用了当前 API Key”推断返回数据属于密钥独立额度：`src-tauri/src/services/usage_service.rs:12-49`。
- 供应商账户查询从启用、未耗尽的密钥中选最低 priority 的一个（必要时回退 provider token）；其结果不是所有密钥额度的合计：`src-tauri/src/services/balance_service.rs:204-214,251-257`。
- 现有测试命令仅做离线脚本校验；刷新命令只接受已保存 ID 且会写缓存，无法直接测试未保存草稿：`src-tauri/src/commands/balance.rs:19-65,76-127,135-167`、`src/renderer/api/types.ts:197-225`。草稿测试需要独立无持久化入口。
- 保存密钥后，首次配置或脚本改变会触发一次刷新；仅改变 key value 不会因已有缓存而重新刷新，可能遗留旧凭据对应的结果：`src/renderer/pages/Keys.tsx:485-497`。
- 查询方案选择不能借用 `presetId` 作为运行时配置；该字段只标记初始化来源，用户可能改过地址或脚本：`.trellis/spec/cc-use/backend/query-script.md:54-76`、`src-tauri/src/shared_runtime/provider_presets.rs:1-11`。旧脚本只能有证据地匹配，无法识别的要保留自定义原文。
- 现有密钥结果已可显示余额和周期窗口，但不会标注查询结果的账户/密钥归属：`src/renderer/pages/Keys.tsx:803-831,870-879`。
- 已查看历史任务需求与当前脚本规范，相关兼容决策就在这些文档中，本轮不另行提取原始对话历史：`.trellis/tasks/archive/2026-11/11-06-command-code-multi-query/prd.md:19-24,28-32`。

## Requirements

- R1：普通路径提供具名内置查询方案、必要凭据与清晰状态，不默认展示代码；自定义脚本作为显式进阶路径。新建时明确选择支持的方案后启用查询；不因预填文本、打开弹窗或已有关闭状态而自动启用。
- R2：供应商查询账户余额与套餐周期用量；密钥只查询当前这把密钥的独立额度，不查询/展示所属账户余额，不展示 5 小时、周、月等套餐周期窗口。两边统一操作语言，但方案目录、查询内容和结果展示分开。供应商账户方案不能直接继承到密钥。
- R3：缺少凭据、未支持独立查询、关闭查询等状态给出可执行的解释，不要求用户自行猜测或删除代码。
- R4：支持未保存草稿的查询测试与可理解的结果/失败反馈；测试仅由用户显式触发，不持久化草稿或污染正式缓存，保存校验仍保持无网络。既有保存后首次刷新与自动刷新需和“保存校验”明确区分。
- R5：既有查询与自定义脚本不丢失；关闭只停止查询并持久化保留配置，再次开启恢复；复制密钥不损失查询配置。旧脚本仅有明确证据时归类，不静默升级；明确属于账户查询的旧密钥脚本停止执行、保留原文并提示修复。不得读取、展示或记录真实密钥/令牌用于开发调研。
- R6：查询结果对应的地址、凭据、方案改变后，不把上一次配置的成功结果继续视为当前配置结果；草稿修改后测试结果须失效。
- R7：选择查询方案不修改供应商名称、图标、推理地址、模型或客户端配置；查询配置与初始化预设分离。

## Acceptance Criteria

- [ ] A1 / R1：选择已支持的内置方案后，无需编辑代码即可配置；代码只在主动进入自定义后可见。新建明确选择内置方案后开启，打开弹窗、预填文本和编辑已有关闭状态不触发隐式开启。
- [ ] A2 / R2：供应商可展示账户余额与周期用量；密钥配置方案、测试预览和卡片只展示当前密钥额度，不出现账户余额/套餐窗口。无独立密钥适配时不能选择账户方案作为替代，也不能从供应商缓存复制额度。
- [ ] A3 / R3：缺少密钥/令牌/用户 ID、关闭查询、无内置方案时，都显示明确说明。
- [ ] A4 / R4：未保存草稿可显式测试；取消编辑后不留下测试配置或正式缓存。结果不泄露凭据，不把缺失数据显示为零，不将失败覆盖为成功。
- [ ] A5 / R5：重开、编辑、复制、导入导出不丢查询方案、启用状态与脚本；关闭保存再打开可恢复原配置。既有自定义脚本不被自动覆盖，明确属于账户查询的旧密钥脚本保留原文且停止执行并有提示；关闭状态不被自动重启。
- [ ] A6 / R6：修改测试输入后不再展示旧的“测试成功”；更换正式密钥/地址/方案时旧结果被失效或明确标为旧配置，不伪装成当前结果。
- [ ] A7 / R7：在查询区切换内置方案或自定义时，非查询配置保持原值。

## Out of Scope

- 不重构模型管理、客户端连接设置或推理协议。
- 不新增未经证实的供应商查询接口、自动登录、Cookie 管理或任意跨域凭据发送。
- 不触碰真实凭据、不发送真实推理/计费调用。

## Confirmed Product Decisions

- D1（用户于 2026-11-09 明确）：密钥只查询当前密钥的额度。拒绝此前“密钥下同时支持所属账户余额/套餐用量”的建议；密钥不展示周/月等套餐窗口。此决定约束 R2 / A2。
- D2：供应商与密钥均纳入本次交互改造；默认不暴露脚本，进阶自定义保留。此决定约束 R1 / A1。
- D3（用户于本轮明确）：新建供应商或密钥时，用户在查询区明确选择支持的内置方案后启用查询；保存后可触发只读额度查询。已有关闭状态保持不变，无适配时不自动启用。
- D4（用户于本轮明确）：关闭查询并保存后保留方案与自定义脚本，只停止查询；再次开启恢复原配置，不清除共享的 API 密钥或供应商凭据。
- D5（用户于本轮明确）：旧脚本保留原文，不因查询方案交互上线而静默升级；只对明确匹配的脚本归类，其他原文保留为自定义。密钥中明确属于账户查询的旧脚本停止执行并保留原文，提示改用独立密钥方案；其他自定义密钥脚本保留，但不展示周期窗口。现有 Command Code 修复升级作为独立既有改动保留。
