# 模型显式添加

日期：2026-10-26

## 问题

密钥编辑器的“模型管理”在首次拿到供应商目录时，会把全部目录模型自动加入 `selected`。用户切到“指定列表”时看起来像是已经添加，但实际还要“应用 → 保存”才落库，容易误判。

## 改动

- 删除首次加载的自动全选；`selected` 只从已保存的 `value.models` 初始化。
- 切换“供应商模型 / 指定列表”不自动全选；只有用户勾选、取消或手动输入才改变选择。
- 空选择时显示“还没有选择模型”的提示；点“应用”仍要求至少一个模型。
- 刷新获取结果只更新候选列表，不修改已保存的 `value.models`；自定义模型不会被覆盖。
- 不改变 `model_mapping` 的 `version:2` 结构和 `catalog.mode` 语义。

## 验收

- 全新密钥打开模型管理：没有任何模型被预先勾选。
- 勾选两个 → 应用 → 保存 → 重开只剩两个。
- 再次获取目录不改变这两个模型。
- 供应商级“查看模型”仍是只读列表，不承担添加。
