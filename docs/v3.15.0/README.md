# cc-use 3.15.0

发布日期：2026-10-26
发布基线：v3.14.2

本版本在 3.14.2 已验证的供应商/密钥、CLI 启动、Desktop 接管和用量统计之上，新增常驻网关出口，并收敛 5 项体验与正确性问题。

## 边界

- 网关只做透明转发，不做协议转换，不承诺同时兼容两种协议。
- 不恢复 v4 的规则/模型三层配置模型。
- 不新增网关级统计、多用户、组织或计费体系。
